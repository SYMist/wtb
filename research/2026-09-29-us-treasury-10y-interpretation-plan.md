# 미국채 10년 금리 해석 카드 — P0 소형 실험 기획

상태: **다음 기능 기획 P0·검증 전**. 2026-09-29 사용자 배정에 따른 기획 우선순위이며 구현·공개·배포 승인이 아니다.

## 풀 질문과 최소 화면

질문은 “미국 10년물 금리가 왜 화제인가, 지금 수치와 이전 선택일 대비 변화가 무엇을 뜻하는가”다. 최소 화면은 미국 재무부 일별 자료의 10년 명목 CMT와 10년 TIPS 실질금리를 같은 선택일 두 개에 표시하고, bp 변화와 명목−실질 차이를 보여준다. 원천 URL, 최종 관측일, 갱신 실패 상태를 함께 보인다.

설명은 고정금리 채권의 수익률 상승과 기존 가격 하락의 관계, 정책금리와 10년물의 차이를 짧게 다룬다. 명목−실질 차이에는 물가보상 외 위험·유동성 프리미엄 등이 섞일 수 있으므로, 이 값으로 금리 상승 원인을 확정하지 않는다. 특정 채권 가격·투자 수익률을 CMT만으로 계산하지 않는다.

## 기획 전 최소 검증

1. 미 재무부의 일별 명목 수익률과 TIPS 실질 수익률에서 10년 항목의 단위, 공통 관측일, 결측·휴장·개정 처리, 갱신 방식과 유지비를 확인한다.
2. 질문형 한국어 쿼리와 현재 모바일 SERP를 같은 관측일·표본으로 남겨, 기사 제목이 아닌 실제 과업과 경쟁 결과가 답하지 못하는 부분을 확인한다.
3. 위 최소 화면이 한 질문을 끝까지 답하는지, 데이터 경고·갱신 실패를 포함해 운영 가능한지 검토한다. 2년·30년, 한미 비교, 2년–10년 스프레드, 환율 손익분기는 이 실험에서 보류한다.

직접 행동은 구현 승인 뒤 사용자가 두 날짜를 명시 제출한 경우만 측정 후보로 둔다. 화면 도착·딥링크·기본 렌더는 행동으로 읽지 않는다. 설명을 열거나 읽은 사실도 이해·투자 판단 완료로 해석하지 않으며, 이해도는 별도 사용자 검증 없이는 측정 불가로 남긴다.

## 데이터 경계와 판정

기존 `/data/rates/treasury-10y`는 **한국 국고채 10년 월평균**이다. 미국 재무부의 일별 명목·실질 시계열과 데이터 원천, 갱신 주기, 단위, 페이지·차트를 공유하거나 한 계열처럼 표시하지 않는다. 한미 비교는 별도 질문·원천 정렬·환율 기준이 확인될 때만 후속 후보로 다룬다.

다음 관측 중 하나라도 성립하면 P0 기획을 뒤집거나 축소한다: 공식 원천을 안정적으로 보관·갱신할 수 없거나 동일 날짜 비교가 불가능함, 모바일 경쟁 결과가 최소 화면의 답을 이미 충족함, 또는 확인 가능한 질문·직접 행동이 최소 화면과 맞지 않음. 최근 기사·헤드라인은 관심의 정성 신호일 뿐 검색량·구현 수요의 증거가 아니다.

기준금리 과거 월 조회는 이미 배포된 기능으로 운영 관찰을 계속한다. 주유비 우회 순절감, 휴대폰 교체 총비용, 재산세와 다른 신규 후보의 검증·구현은 이 P0 판정 뒤로 미룬다.
