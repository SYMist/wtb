# 미국채 10년 금리 해석 카드 — P0 소형 실험 기획

상태: **다음 기능 기획 P0·검증 전**. 2026-09-29 사용자 배정에 따른 기획 우선순위이며 구현·공개·배포 승인이 아니다.

## 풀 질문과 최소 화면

질문은 “미국 10년물 금리가 A에서 B까지 얼마나 움직였고, 같은 기간 내가 보는 값은 어떻게 달라졌는가”다. 기본 선은 FRED `DGS10` 일별 10년 만기 CMT 역사 그래프다. 사용자가 A/B 두 시점을 고르면 각 실제 관측일·수익률·bp 차이를 표시한다. 긴 기간은 화면 표시만 집계하고 A/B 계산은 원 관측값으로 한다.

첫 체감 카드는 고정 달러 지출(예: 1,000달러)의 원화 환산 차이다. FRED `DEXKOUS`의 같은 기간 관측 환율과 환산액을 별도 관측 사실로 보이며, 미국채 금리가 환율 변화를 일으켰다고 쓰지 않는다. `DEXKOUS`는 뉴욕 정오 cable transfer 기준이라 국내 은행의 실제 결제환율도 아니다.

두 번째 카드는 시장금리 상승과 기존 고정금리 채권 가격 하락의 관계를 방향 그림으로 설명한다. 보유 종목·쿠폰·듀레이션이 없으므로 특정 미국채의 평가액·수익률을 숫자로 단정하지 않는다. 관측 패널 제목은 **“같은 기간 함께 변한 값”**, 설명 패널 제목은 **“영향을 받을 수 있는 경로”**로 분리한다. 한국 대출·물가·주가는 미국채 금리 두 점만으로 산출하거나 원인을 확정하지 않는다.

## 데이터·권리·시점 계약

2026-09-29 공식 FRED 페이지 기준 `DGS10`과 `DEXKOUS`의 최신 관측일은 모두 2026-09-25, 갱신 표시는 9월 28일이며 둘 다 일별이다. `DGS10`의 출처는 Federal Reserve Board H.15, `DEXKOUS`는 Board H.10이고 FRED는 두 계열에 Public Domain: Citation Requested를 표시한다. 그래도 FRED API 약관은 계열 소유자의 제한·저작권을 별도로 준수하라고 요구하므로, 구현 직전 계열 notes와 출처 이용조건을 다시 확인하고 인용·출처를 표시한다.

FRED API는 등록 API key가 필요하다. 키는 클라이언트·Git에 두지 않고, 약관 링크와 “FRED API를 사용하지만 St. Louis 연은의 보증·인증을 받지 않았다”는 요구 고지를 반영할 수 있을 때만 사용한다. FRED의 핵심 사용자 경험을 대체하는 범용 그래프 복제는 금지되므로, 한국어 질문의 A/B 비교·원화 관측·해설에 한정한다.

A/B는 `DGS10`의 유효 관측일로 스냅하고 선택된 실제 날짜를 표시한다. `DEXKOUS`는 각 유효일의 같은 날짜 관측이 있는지 먼저 확인한다. 미국 공휴일·환율 공표일 불일치에서 임의 전방 채움이나 같은 날인 척한 비교를 하지 않고, 공통 관측일 정렬 규칙·별도 실제 관측일 표기·카드 숨김 중 어떤 방식이 정확한지 기획 검증에서 결정한다. 최신값은 “현재”로 단정하지 않고 각 계열 관측일을 쓴다.

`MORTGAGE30US`는 미국 30년 고정 모기지 평균이며 Freddie Mac 원천·주간 목요일 종료 계열이다. 2026-09-29 FRED 표시는 최신 2026-09-24 관측이다. FRED가 저작권 검토를 요구하고 일별 DGS10과 빈도가 다르므로, Freddie Mac 사용권·귀속·주간 정렬과 미국 거주자 맥락을 확인하기 전에는 보조 카드와 가상 원리금 비교를 보류한다.

## 기획 전 최소 검증

1. FRED API key·약관 고지, `DGS10`·`DEXKOUS` 계열 notes/출처의 권리와 인용, 갱신·개정·캐시 방식을 확인한다.
2. A/B 선택일과 두 일별 계열의 휴장·결측·공통 관측일 정렬을 실제 표본으로 검증한다.
3. 질문형 한국어 쿼리와 현재 모바일 SERP를 같은 관측일·표본으로 남겨, 기사 제목이 아닌 실제 과업과 경쟁 결과가 답하지 못하는 부분을 확인한다.
4. 이 최소 화면이 한 질문을 끝까지 답하고 오류·갱신 실패를 표시할 수 있는지 검토한다. 직접 행동은 구현 승인 뒤 A/B를 명시 제출한 경우만 측정 후보로 둔다. 화면 도착·딥링크·기본 렌더·설명 열람은 이해나 투자 판단 완료가 아니다.

2년·30년, 명목−실질 분해, 한미 비교, 2년–10년 스프레드, 환율 손익분기, 미국 모기지, 한국 대출·물가·주가 영향은 이 실험에서 보류한다. 공식 원천·권리·정렬을 안정적으로 유지할 수 없거나, 모바일 경쟁 결과가 최소 질문을 이미 충족하거나, 확인 가능한 질문·직접 행동이 화면과 맞지 않으면 P0를 뒤집거나 축소한다. 최근 기사·헤드라인은 관심의 정성 신호일 뿐 검색량·구현 수요의 증거가 아니다.

## 데이터 경계와 다음 순서

기존 `/data/rates/treasury-10y`는 **한국 국고채 10년 월평균**이다. FRED의 미국 일별 시계열과 원천·단위·갱신·페이지·차트를 섞거나 한 계열처럼 표시하지 않는다. 한미 비교는 별도 질문·원천 정렬·환율 기준이 확인될 때만 후속 후보로 다룬다.

기준금리 과거 월 조회는 이미 배포된 기능으로 운영 관찰을 계속한다. 주유비 우회 순절감, 휴대폰 교체 총비용, 재산세와 다른 신규 후보의 검증·구현은 이 P0 판정 뒤로 미룬다.
