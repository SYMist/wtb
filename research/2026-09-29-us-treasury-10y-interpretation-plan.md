# 미국채 10년 금리 해석 카드 — P0 소형 실험 기획

상태: **Federal Reserve Board 원천의 실제 관측값 구현·운영 배포 완료, 독립 라이브 검수 대기**. 2026-09-29 사용자 승인으로 `0f8a8d8`까지 GitHub `main`에 반영하고 Worker `wtb` version `d28c0b24-8081-414d-a9ea-03b689bd8251`를 배포했다.

## 풀 질문과 최소 화면

질문은 “미국 10년물 금리가 A에서 B까지 얼마나 움직였고, 같은 기간 내가 보는 값은 어떻게 달라졌는가”다. 기본 선은 Federal Reserve Board H.15 일별 10년 만기 CMT 역사 그래프다. 사용자가 A/B 두 시점을 고르면 각 실제 관측일·수익률·bp 차이를 표시한다. 긴 기간은 화면 표시만 집계하고 A/B 계산은 원 관측값으로 한다.

첫 체감 카드는 고정 달러 지출(예: 1,000달러)의 원화 환산 차이다. Board H.10의 같은 기간 관측 환율과 환산액을 별도 관측 사실로 보이며, 미국채 금리가 환율 변화를 일으켰다고 쓰지 않는다. H.10은 뉴욕 정오 cable transfer 기준이라 국내 은행의 실제 결제환율도 아니다.

두 번째 카드는 선택한 B−A에 맞춰 **“시장 수익률 ↑ → 기존 고정금리 채권 가격 ↓”** 또는 그 반대 방향을 작은 표시와 설명으로 보여준다. 0bp면 두 값 모두 “변화 없음”으로 표시한다. 보유 종목·쿠폰·듀레이션이 없으므로 특정 미국채의 평가액·수익률을 숫자로 단정하지 않는다. 관측 패널 제목은 **“같은 기간 함께 변한 값”**, 설명 패널 제목은 **“영향을 받을 수 있는 경로”**로 분리한다. 한국 대출·물가·주가는 미국채 금리 두 점만으로 산출하거나 원인을 확정하지 않는다.

## 데이터·권리·시점 계약

2026-09-29 Board H.15/H.10 릴리스 XML 기준 최신 관측일은 모두 2026-09-25다. H.15 10년은 5.17%, H.10 South Korean won per U.S. dollar는 1,356.5100원이다. 각각의 XML 헤더 준비 시각은 2026-09-28 15:40:03과 13:35:00이다. Board의 웹 자료는 별도 표시가 없으면 public domain으로 복제·배포할 수 있고 Board 출처 인용을 요청한다. 화면에는 H.15·H.10 원천·관측 시점과 갱신 실패 시 수치를 꾸미지 않는 경로를 표시한다.

갱신은 릴리스 자체 XML 고정 경로 `FRB_h15_xml.zip`, `FRB_h10_xml.zip`을 사용한다. DDP Build Your Package는 2026-11 폐지 예정이므로 사용하지 않는다. 다운로드한 원본 ZIP은 저장하지 않고, 필요한 두 공개 계열의 전체 일별 관측값(H.15 1962년~, H.10 1981년~)과 준비 시각만 `lib/data/us-treasury-interpretation.json`에 추린다. 기본 그래프는 최근 5년이고 전체 전환 시 표시점만 축약한다. FRED는 관련 계열 DGS10·DEXKOUS의 링크로만 표시하며 API를 호출하지 않는다.

A/B는 H.15의 유효 관측일로 스냅하고 선택된 실제 날짜를 표시한다. H.10은 각 유효일의 같은 날짜 관측이 있는지 먼저 확인한다. 미국 공휴일·환율 공표일 불일치에서 임의 전방 채움이나 같은 날인 척한 비교를 하지 않고, 환율 카드만 숨긴다. 최신값은 “현재”로 단정하지 않고 각 계열 관측일을 쓴다.

`MORTGAGE30US`는 미국 30년 고정 모기지 평균이며 Freddie Mac 원천·주간 목요일 종료 계열이다. 2026-09-29 FRED 표시는 최신 2026-09-24 관측이다. FRED가 저작권 검토를 요구하고 일별 DGS10과 빈도가 다르므로, Freddie Mac 사용권·귀속·주간 정렬과 미국 거주자 맥락을 확인하기 전에는 보조 카드와 가상 원리금 비교를 보류한다.

## 기획 전 최소 검증

1. Board H.15/H.10 릴리스 XML의 고정 경로, public-domain 재사용·출처 인용, 원천별 준비 시각을 확인한다.
2. A/B 선택일과 두 일별 계열의 휴장·결측·공통 관측일 정렬을 실제 표본으로 검증한다.
3. 질문형 한국어 쿼리와 현재 모바일 SERP를 같은 관측일·표본으로 남겨, 기사 제목이 아닌 실제 과업과 경쟁 결과가 답하지 못하는 부분을 확인한다.
4. 이 최소 화면이 한 질문을 끝까지 답하고 오류·갱신 실패를 표시할 수 있는지 검토한다. 직접 행동은 구현 승인 뒤 A/B를 명시 제출한 경우만 측정 후보로 둔다. 화면 도착·딥링크·기본 렌더·설명 열람은 이해나 투자 판단 완료가 아니다.

2년·30년, 명목−실질 분해, 한미 비교, 2년–10년 스프레드, 환율 손익분기, 미국 모기지, 한국 대출·물가·주가 영향은 이 실험에서 보류한다. 공식 원천·권리·정렬을 안정적으로 유지할 수 없거나, 모바일 경쟁 결과가 최소 질문을 이미 충족하거나, 확인 가능한 질문·직접 행동이 화면과 맞지 않으면 P0를 뒤집거나 축소한다. 최근 기사·헤드라인은 관심의 정성 신호일 뿐 검색량·구현 수요의 증거가 아니다.

## 데이터 경계와 다음 순서

기존 `/data/rates/treasury-10y`는 **한국 국고채 10년 월평균**이다. Board H.15/H.10의 미국 일별 시계열과 원천·단위·갱신·페이지·차트를 섞거나 한 계열처럼 표시하지 않는다. 한미 비교는 별도 질문·원천 정렬·환율 기준이 확인될 때만 후속 후보로 다룬다.

기준금리 과거 월 조회는 이미 배포된 기능으로 운영 관찰을 계속한다. 주유비 우회 순절감, 휴대폰 교체 총비용, 재산세와 다른 신규 후보의 검증·구현은 이 P0 판정 뒤로 미룬다.

## 2026-09-29 구현 기록

`/data/us-treasury-10y`를 한국 국고채 페이지와 별도 경로로 만들었다. Board H.15 그래프, 그래프 탭 두 번의 A/B 선택(첫 탭 A, 둘째 탭 B), 키보드 대체 날짜 입력, 실제 관측일·bp 차이, 같은 날짜 H.10의 1,000달러 원화 환산, 고정금리 채권 가격의 방향 설명을 표시한다. 날짜 선택은 H.15의 직전 유효 관측일로만 보정하고, H.10이 두 실제 날짜에 모두 없으면 환산 카드를 표시하지 않는다. 최근 5년 밖의 유효 날짜를 폼으로 제출하면 두 기준선이 보이도록 전체 그래프로 자동 전환한다. 이 규칙은 주말 스냅, 10bp, 12,500원 환산 차이, 환율 결측 비전방채움, 두 그래프 점 선택을 포함한 단위 테스트로 확인한다.

갱신 스크립트는 원본 Board XML ZIP을 임시 디렉터리에만 받고 필요한 전체 일별 두 계열과 준비 시각을 저장한다. 네트워크·형식·계열·관측값 검증이 실패하면 출력 파일을 쓰기 전에 종료하므로 기존 검증본을 지운 채 배포하지 않는다. 관측값 배열이 같으면 확인일·릴리스 준비 시각만으로 JSON을 다시 쓰지 않아 커밋·배포를 만들지 않는다. 원천 확인일이 8일을 넘으면 화면에 최신값으로 단정하지 말라는 경고를 표시한다. GitHub Actions는 Board H.15 발표 뒤 평일 22:00 UTC에 점검하고, 실제 변경일 때만 테스트·Cloudflare build·`wtb` 배포·데이터 커밋을 실행한다. workflow 동시 실행은 직렬화하며 실패하면 기존 원격 JSON과 Worker 버전을 보존한다.
