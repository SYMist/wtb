## 상위 두 후보 판독

### 1. 배터리 수리 vs 기기 교체 — 조건부 추천

- **확인된 사용자 질문:** “배터리만 바꿔서 더 쓰는 비용과 새 기기를 사는 비용을 같은 기간 기준으로 어떻게 비교하지?” Naver HTML에서 교체비·중고가·사용기간을 나란히 설명하는 최근 정보 글을 확인했다. 이는 문제가 설명되고 있음을 보일 뿐, 검색량·Tooly 유입·유료 의도를 증명하지 않는다.
- **현재 빈틈:** [24개월 통신/구매 계산기](https://mobilephoneclass.com/calculator)는 단말기 구매 방식의 총액을 다룬다. 이 조사에서 직접 열람한 화면은 배터리 견적과 현재 기기 보유기간을 새 기기 비용과 맞춰 비교하지 않았다. Apple 공식 페이지는 모델을 골라 예상비용을 보여 주고 최종 요금은 기기 점검 후 정해질 수 있다고 밝힌다. 삼성 공식 안내는 모델별 배터리 교체비를 서비스 챗봇으로 안내한다고 설명한다. 제조사·모델마다 입력 방식이 달라 가격표를 Tooly가 복제할 이유가 없다.
- **작은 실험 범위:** 잠정 경로는 `/life/phone-repair-vs-replace`지만 아직 URL 채택은 아니다. 배터리 수리 견적, 현재 폰 수리 후 예상 추가 사용 개월, 새 폰의 실결제액(중고 매입/반납 차감 후), 새 폰 예상 사용 개월만 수동 입력받는다. 각 선택의 선불 비용과 비용/사용월을 나란히 산출한다. 다른 고장·성능·편의 가치를 수치화하지 않고 “최저가 선택”을 권하지 않는다. 가격 크롤링, 제조사별 사전 채움, 통신사 지원금 비교는 범위에서 뺀다.
- **정확성·관리:** 식은 수리안 월비용=`수리 견적 ÷ 예상 추가 사용월`, 교체안 월비용=`새 기기 실부담 ÷ 예상 사용월`이다. 사용 개월 0 이하, 음수 비용, 중고 매입 차감 초과는 유효하지 않게 처리한다. 사용자 입력 견적·수명은 예측값이므로 결과에 동일하게 노출한다. 공식 비용 고시 기준일/실제 점검 변동을 안내하고, 배터리 외 기기 고장을 고치지 않는 계산이라고 명시한다. 매뉴얼 입력 MVP라 모델 데이터 유지가 없고 입력·결과 흐름 한 번의 범위다.
- **차별 경험:** 공식 서비스는 자기 제품 견적, 구매 비교기는 기기·요금 계약을 각각 제공한다. Tooly 실험은 “수리해서 더 쓸지 교체할지”를 본인이 받은 견적과 예상 보유기간만으로 공통 월비용에 환산한다. 경쟁사가 이 동일 비교를 이미 제공하거나 사용자 인터뷰에서 견적/수명을 입력할 수 없으면 차별성 가설은 기각한다.
- **성공·반증 관측:** 사전 과업 명료성은 소규모 목표 사용자 5명 테스트에서 4명 이상이 본인 견적으로 계산을 끝내고 “비용/월은 성능·수리 성공을 보장하지 않는다”를 바르게 설명하는 것을 통과선으로 제안한다. 이는 사용성 신호이지 시장 수요·사업성과가 아니다. 기능을 배포하는 경우 Search Advisor에서 정확 쿼리·URL 행의 같은 PC+모바일 14일 baseline과 첫 14일 노출/클릭을 비교하고, 제출 완료는 실제 제출만 따로 측정한다. 표본이 부족하면 성공/실패가 아니라 판정 불가다. Search Advisor 현재 쿼리 baseline은 접근 후 먼저 확보해야 하며 지금 값은 미측정이다.
- **비용·한계:** 수동 입력형 단일 반응형 계산과 입력 오류·경계 검산이 핵심이다. 향후 제조사 가격 DB, 중고 시세, 성능 점수, 보상판매 자동 수집을 붙이면 유지비와 잘못된 추천 위험이 크게 늘어난다. 이번 추천은 그런 범위 확장이 아니다.

### 2. 주유소 우회 순절감 — 보류

- **질문·입력→출력:** 예정 주유량 × (기준 주유소 가격 − 싼 주유소 가격)에서 추가 주행거리 ÷ 실제 연비 × 주유 가격을 뺀 순절감. 주유소를 위해 왕복하는지 출퇴근 동선에 이미 포함되는지도 구분해야 한다.
- **공식 원천·경쟁:** Opinet은 실시간 가격·지역별 Top20·반경검색·주유소 상세를 제공하고 사이트 메뉴에도 경로별 검색을 둔다. API 신청 후 일반 키와 호출 한도가 있고, 지역별 전체 데이터는 유료 프리미엄 범위다. 더 직접적인 [기름주의보](https://oil.bodeum.me/route)는 경로·연비·주유량 맥락, 우회 허용시간과 시간/가격 선호로 추천까지 제공한다. 현재는 Tooly가 더 쉽게 할 비교 과업이 좁다.
- **반증·재개:** 키 없이 사용자가 가격과 추가 km만 넣는 순수 계산기는 저렴하지만 검색 결과에 있는 경로 도구보다 사용자가 더 많이 입력한다. Tooly용 exact query rows가 반복되거나 실제 사용자 과업에서 “목적지 경유 주유가 아니라, 예정량 기준 얼마 아끼는가”가 현 제품에서 해결되지 않는다고 확인될 때만 작은 계산을 다시 평가한다. 현재 검색량과 실제 사용 행동은 미측정이다.
