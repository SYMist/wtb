이번 결론은 **신규 페이지 추천 없음 · 추가 입력 대기**다. 핵심 게이트인 현재 SERP 공백을 직접 확인하지 못했고, 가장 강한 두 수요는 이미 존재하는 URL이 과업을 상당 부분 수행한다.

## 4. 기존 Tooly 승리 표면

최신 표본에서 `/data`가 Top 30 클릭의 91.15%이고, 단일 과거시점 쿼리도 50/1,438을 유지한다. 이는 일반 현재값보다 **과거 월·연도 시계열**이 확인된 승리 표면이라는 증거다. 이전 표본의 환율 클러스터 226클릭과 `월별 환율 비교`의 10.6% CTR도 기간·비교 의도가 인접함을 보인다.

반면 현재값 환율은 네이버 위젯이 답을 끝낸다는 수동 전달 관측과 과거 전략 기록이 일치한다. 그 노출 규모는 회수 가능한 수요로 세지 않는다. blog 비중도 최신 Top 30에서 53/768이므로 신규 블로그나 범용 계산기로 확장하지 않는다.

## 5. 키워드 클러스터링 방법

1. 제공된 실제 쿼리·URL 수치에서 `월별`, 과거 연월, `추이`에 해당하는 행을 씨앗으로 삼았다.
2. 씨앗을 사용자 과업으로 묶었다: 두 시점 환율 비교·환산, 과거 기준금리 조회·기간 비교, 국고채 추이·만기 비교.
3. 이미 구현된 화면과 대조해 새 URL이 필요한지 분리했다. 환율 비교와 CPI 화폐가치 환산은 이미 정확한 기능이 있으므로 신규 후보가 아니라 기존 URL 확장 후보로 판정했다.
4. 각 클러스터를 G1~G8로 평가했다. 수치가 없거나 현재 SERP를 보지 못한 핵심 게이트는 `확인 불가`로 남겼다.

## 7. 후보별 SERP 공백

- **환율:** 과거 기록과 사용자 입력 모두 단순 현재 환율·표는 위젯/기관에서 끝날 수 있음을 경고한다. Tooly의 차별점은 두 시점과 금액 환산이지만, 현재 네이버 결과에서 이 기능이 실제 공백인지는 확인하지 못했다.
- **기준금리:** 2026-09-08 관측에서는 Tooly 과거값이 스니펫에 직접 드러났다. 이는 검색 결과가 단일값을 상당 부분 답한다는 반례다. 기간 비교를 별도 과업으로 입증할 쿼리 행과 SERP가 없다.
- **국고채:** 공식/증권 결과가 현재값만 주는지, 기간·복수 만기 조작까지 제공하는지 확인하지 못했다. 공백을 단정하지 않는다.
- **CPI:** Tooly 기능 차별점은 명확하지만 수요와 SERP 모두 결측이다. 기능 존재를 수요로 바꾸지 않는다.

## 8. 후보별 공식 데이터와 유지 가능성

모든 현재 시계열은 한국은행 ECOS API 기반이며 기존 `.github/workflows/update-ecos-data.yml`이 **월 1회** 실행한다. 변화가 없으면 커밋하지 않는 경로도 이미 있다. 환율·base·CPI는 기존 공식 통계 코드와 보존/기준연도 가드가 있어 재사용성이 높다.

국고채 복수 만기는 아직 10년 외 항목 코드·시작일·단위·과거 연속성을 확인하지 않았다. 특히 10년 수집기는 당월 말일까지 요청해 현재 미완료월의 부분 평균이 파일에 들어갈 수 있으므로, 비교 기능 전에 완결월 정책을 확인해야 한다. 이 위험 때문에 G3/G6을 자동 통과시키지 않았다.

ECOS 웹사이트 이용조건의 최신 전문은 네트워크 실패로 직접 확인하지 못했다. 기존 페이지는 출처 링크와 Dataset schema를 제공하지만, 신규 배포 판단 전 API 이용조건과 표시 의무를 공식 문서에서 다시 확인해야 한다.

## 10. 신규 페이지 추천 최대 1개

**0개.** 추천 후보용 working page name·최소 기능·구현 범위는 작성하지 않는다. 핵심 입력이 없는 상태에서 구현 지시서로 오인될 내용을 만들지 않는다.

## 11. 추천 없음도 가능한 최종 판정

최종 판정은 **신규 페이지 추천 없음 · 추가 입력 대기**다.

- 가장 강한 수요인 환율 월별 비교는 이미 `/data/exchange/compare`가 두 시점·금액 환산·계측을 제공해 G7이 실패한다.
- 가장 큰 확인 수요인 기준금리 과거월은 현재 `/data/rates/base`와 검색 스니펫이 값을 답한다. 별도 URL은 중복이다.
- 새 URL 명분이 가능한 국고채 만기 비교는 G2·G3·G5·G6이 확인 불가다.
- CPI 화폐가치 환산은 기능은 이미 있으나 G1 수요 근거가 없다.

이 결론을 가장 쉽게 뒤집는 증거는 (1) 최신 쿼리 export에서 국고채 복수 만기·스프레드 클러스터가 반복 노출되고, (2) 현재 모바일 SERP가 기간/만기 비교를 제공하지 않으며, (3) ECOS 복수 만기 연속 시계열과 완결월 정책이 확인되는 조합이다.

## 12. 자동화: 일별 수집·변화 감지·주별 해석

### 12.1 일별 수집

**추천 0개.** 일별 수집할 이유가 입증되지 않았다. 공식 시계열은 월별이고 기존 월 1회 ECOS workflow가 변화 없을 때 커밋하지 않는다. Search Advisor는 UI에 1/7/30/60/90일만 있고 저장소에 안정적인 API/export 경로가 확인되지 않았다. OAuth·계정 설정 변경 없이 일별 숫자를 보존할 경로도 없다.

후속 수동 조사에서 안정적인 export/API가 확인되면 일별이 아니라 **주간 우선**으로 URL/쿼리별 기간·분모·클릭·노출·CTR·순위와 신규 쿼리만 LLM 없이 저장하는 안을 검토한다. 계정 연결은 별도 사용자 승인 대상이다.

### 12.2 조건부 변화 감지

지금 구현하지 않는다. 향후 저장된 동일 창이 생기면 `신규 쿼리`, `고노출·저클릭`, `인접 쿼리 연속 상승`, `신규 URL 최초 색인/노출`, `공식 원천 갱신`, `SERP 구성 변경` 플래그를 낼 수 있다. 근거가 없어 숫자 임계값은 만들지 않는다. 변화가 없으면 무출력이어야 한다.

### 12.3 주별 또는 판정일 해석

일별 LLM 해석은 불필요하다. 같은 스키마의 수동 조사 2회 이상과 우선순위가 실제로 바뀐 사례가 생긴 뒤, 주 1회 이하 또는 변화 플래그 발생 시에만 후보·변화·다음 행동을 짧게 해석한다. 페이지 생성·배포로 연결하지 않는다.

## 13. 자동화 재검토 게이트

| 게이트 | 현재 판정 | 근거 |
|---|---|---|
| A1 수동 2회 이상 | 실패 | 이번이 1회차 |
| A2 우선순위 변경 사례 | 확인 불가 | 반복 수집 비교 없음 |
| A3 안정적 API/export | 일부만 통과 | ECOS는 안정적 기존 경로; 검색 성과는 경로 미확인 |

| A5 주기·담당자 | 확인 불가 | 정해진 검토자/주기 입력 없음 |

## 15. 미해결 입력

최대 3개만 요청한다.

1. **Search Advisor 최신 동일 창 export:** 쿼리 Top 30과 웹문서 Top 30의 전체 행(기간 선택·업데이트일·PC/Mobile 포함). 특히 환율 비교, 국고채 만기/차이, CPI 화폐가치 클러스터 원행.
2. **현재 네이버 모바일 SERP 캡처/구조 기록:** `월별 환율 비교`, `국고채 3년 10년 차이`, `1990년 100만원 지금 가치` 각각 위젯·공식기관·상위 결과의 기간/값 변경 및 비교 기능.
